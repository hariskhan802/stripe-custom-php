# Stripe Integration in PHP

## Overview

**Stripe Custom PHP Integration** is a lightweight and secure implementation of Stripe's payment gateway using core PHP. This project demonstrates how to integrate Stripe seamlessly into a web application, enabling functionalities like payment processing, refunds, and transaction tracking.

---

## Key Features

- **Payment Processing**: Accept credit and debit card payments securely.
- **Refunds**: Handle partial or full refunds for completed transactions.
- **Transaction History**: Fetch and display transaction details.
- **Customizable Design**: Easily integrate the payment form into your existing website.
- **Secure Integration**: Adheres to Stripe's best practices for API usage and data handling.

---

## Technical Highlights

- **Core PHP**: Lightweight and efficient backend implementation.
- **Stripe PHP SDK**: Utilized the official Stripe library for seamless API interactions.
- **Secure Environment**: Environment variables for sensitive data like API keys.
- **JSON Webhooks**: Configured for handling real-time updates from Stripe.
- **Error Handling**: Graceful management of payment errors and API failures.

---

## Installation

Follow these steps to set up the Stripe integration on your server:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hariskhan802/stripe-custom-php.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd stripe-custom-php
   ```
3. **Install dependencies:**
   Use Composer to install the Stripe PHP SDK:
   ```bash
   composer install
   ```
4. **Configure environment variables:**
   - Create a `.env` file in the project root.
   - Add your Stripe API keys:
     ```
     STRIPE_SECRET_KEY=your_secret_key
     STRIPE_PUBLISHABLE_KEY=your_publishable_key
     ```
5. **Run the application:**
   Place the project files in your web server's root directory and access the site through a browser.
